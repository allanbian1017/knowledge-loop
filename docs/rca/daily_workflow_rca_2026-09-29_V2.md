# Technical note: Suggestion archetype monoculture

This public copy retains the reusable technical lesson. Personal execution captures, account state, reading history and feedback are excluded; the historical filename is retained for existing links.

## Failure mode

Optimizing for a rubric target can collapse suggestions into repetitive prompt-template proposals even when they do not fit source content.

## Recovery and prevention

Evaluate archetype-content fit. Preserve the five legacy archetypes, route TAKEAWAY_ONLY out of pending actions, and use user-configured goals/preferences. Acceptance records feedback; implementation or external issue creation requires a separate request.

## Verification boundary

Use isolated synthetic fixtures for local contracts and failure injection. Tool authentication, source completeness and hardware throughput require the applicable authorized environment; offline storage tests do not establish them.
