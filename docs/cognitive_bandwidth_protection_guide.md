# 認知頻寬保護策略指南 (Cognitive Bandwidth Protection Strategy Guide)

## 📌 背景與核心理念
本指南基於 2019 年諾貝爾經濟學獎「稀缺理論（Scarcity Theory）」與個人工作流最佳實踐。當個人的注意力被頻繁的切換、緊急但低價值的雜務（如零碎看信、重複性搜集資訊）填滿時，大腦的高階執行功能（Executive Function）與認知頻寬（Cognitive Bandwidth）會被大量消耗，導致無法進行長遠規劃與高價值的系統建構。

本策略旨在透過「系統自動化、時間區隔與堅固邊界」，保護個人的高品質認知頻寬。

---

## 🛡️ 三大落地實踐指南

### 1. 設定「認知保護區」（Cognitive Protection Zone）
- **核心操作**: 每日固定預留 60–90 分鐘專屬時段（如 09:00–10:30），專注於高槓桿的系統建構、演算法練習、系統設計與核心程式碼編寫。
- **硬性運作規則**:
  - 在此區段內，關閉所有通訊軟體與社群媒體。
  - 絕不在保護區內處理零碎郵件或隨機搜尋。
  - 確保每日最清醒的注意力優先分配給重要但不緊急的「長期資產建立」。

### 2. 批次自動吞吐（Batch Ingestion via Daily Workflow）
- **核心操作**: 將日常所有的情報搜集（電子報、Threads、YouTube 影片摘要）統一委派給 `daily-workflow` 自動化管線。
- **硬性運作規則**:
  - 停止隨機散亂的即時閱讀。
  - 每日僅執行一次 `daily-workflow`，讓 AI Agent 批次完成抓取、清洗、提煉與 Knowledge Distillation 報告產出。
  - 個人只需閱讀 5 分鐘的每日精華彙整（Daily Distillation），將 2 小時的資訊處理時間壓縮為極低認知消耗的決策過程。

### 3. 明確的人機分工界線（Strict Human-AI Division of Labor）
- **AI Agent 的責任（低認知消耗 task）**:
  - 原始內文抓取與 Markdown 轉換。
  - 結構化摘要生成與初判分類。
  - 格式檢查、語法驗證與重複性報告產出。
- **個人的責任（高槓桿高價值 task）**:
  - 審視知識提煉報告與跨領域觀點連結。
  - 對 AI 提出的 Suggestion 進行 Accept/Reject 高層次決策。
  - 進行複雜系統架構設計與核心代碼評估。

## 📋 每日認知頻寬保護 Checklist

- [ ] 電子報與社群情報是否已交由 `daily-workflow` 批次處理，而非零碎閱讀？
- [ ] 是否將重複性、低價值的格式處理與檢索工作完全委派給 AI Agent？
- [ ] 是否在面對資訊焦慮時，優先檢查並維持時間容器與邊界？
