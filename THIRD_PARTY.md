# Third-Party Skill Provenance

Required external CLI adapter skills are bundled in this repository so users can run `daily-workflow` immediately after cloning. Preserve upstream notices when redistributing.

| Bundled Skill(s) | Upstream Repository | License |
| :--- | :--- | :--- |
| `agent-browser` | [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser) | Apache-2.0 |
| `gws-shared`, `gws-gmail`, `gws-tasks` | [googleworkspace/cli](https://github.com/googleworkspace/cli) | Apache-2.0 |

Update external skills via `npx skills experimental_install` using `skills-lock.json`. All original Knowledge Loop skills, scripts, MCP servers, and design documents are covered by the repository [LICENSE](LICENSE).
