# User Preference Profile

> Automatically refined by the `review-suggestions` skill as you accept or reject suggestions.

## Preferred Suggestion Traits
- Concrete, hands-on engineering tasks completable in 15–60 minutes
- Direct improvements to existing workflows, architecture, or verification tests
- Clear, measurable expected outcomes

## Avoided Suggestion Traits
- Vague reading/research prompts without a concrete deliverable
- Duplicate rebuilds of capabilities already present in the repository
