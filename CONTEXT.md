# Glossary

## Knowledge Loop Repository
This public repository (`knowledge-loop`). It owns reusable agent skills, sub-agent personas, lifecycle hooks, local MCP servers, scripts, tests, and architecture guidelines — with zero personal data or absolute machine paths.

## Data Repo (`$DATA_REPO`)
A separate private repository (or local directory) holding personal goals, language preferences, suggestion queues, generated reports, and private integration mappings. Bound to the knowledge-loop via gitignored `workspace.local.env` and `repos.local.md`.

## Trace
A structured `.json` or `.md` artifact generated by complex skills (e.g., `agent-browser`) at the end of their execution. It explicitly logs the agent's goal, intermediate tool calls, and final success/failure state, serving as the raw input (memory) for background reflection. Stored temporarily in `.tmp/traces/`.

## Dreamer
An asynchronous batch-processing script (or skill) that runs during downtime (e.g., as part of `daily-workflow`). It consumes accumulated `Trace` files, evaluates them using an LLM to identify recurring errors or anti-patterns, and extracts permanent rules to prevent future failures.

## Memory Injection
The process of permanently storing rules extracted by the `Dreamer`. To prevent global context bloat, the rule is appended locally to the specific skill's `SKILL.md` (e.g., under a `## Known Gotchas & Lessons` section). Concurrently, the skill's `README.md` changelog must be updated to reflect the newly injected rule.
